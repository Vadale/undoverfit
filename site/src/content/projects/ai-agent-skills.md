Reusable workflows for the parts of a project that need more than code generation: establishing goals and constraints, choosing agent responsibilities, preserving context and deciding what belongs in public material.

Start with [Assert Skill](https://github.com/Vadale/assert-skill) for project setup. [Project Continuity](https://github.com/Vadale/project-continuity-skill) supports resuming or handing off work, while [Publication Fit Review](https://github.com/Vadale/publication-fit-review-skill) helps review material for a specified audience.
