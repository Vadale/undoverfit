An open-source R package for using and studying local language models, with reproducible examples and a workflow for extracting structured information from documents.

I define requirements and priorities, coordinate AI-assisted development, and review examples, checks and documentation. The repository contains installation guidance, practical recipes and the limits of the supported workflows.
